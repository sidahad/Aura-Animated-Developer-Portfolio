# Aura - Premium Animated Personal Portfolio Interface

Aura is an interactive, premium multi-page personal portfolio and digital resume template engineered for developers, technical designers, and engineering creatives. Built using fluid front-end responsive structures and a clean utility layout, it features modern micro-interactions, custom interactive viewport elements, and dynamic media carousels.

---

## Workspace Directory Architecture

The configuration leverages a highly organized front-end directory structure inside the `assets/` layout:
* **Preloader & Custom Utilities (`index.html`):** Incorporates structural viewports including hardware-accelerated preloaders (`id="preloader"`) and dynamic follow-cursors (`class="cursor"`).
* **Navigation Architecture (`meanmenu.css`):** Highly flexible navigation sub-systems featuring structural mega-menus, optimized dropdown behaviors, and dynamic responsiveness.
* **Component Presentation Engines:** Integrated modal popups via Magnific Popup scripts alongside multi-device swiper interfaces (`swiper.min.css`).

---

## Technical Composition & Core Libraries

* **Core Interface:** Semantic HTML5 Structure
* **Layout Grid System:** Bootstrap Framework Core Elements (`bootstrap.min.css`)
* **Motion Design Assets:** Advanced entry animations driven via Animate.css configurations
* **Typography & Visual Assets:** Comprehensive web-font libraries including FlatIcon asset vectors (`flaticon_aina.css`) and FontAwesome font-face structures.
* **Layout Management:** Global utility architecture engineered inside `global.css` and individual page scripting in `style.css`.
